ようこそ、こっそり部屋へ。

2018年、YouTube に投稿された1本の「歌ってみた」から、「春を告げる」「色彩」「slash」、そしてアジア・北米・ヨーロッパのステージまで。白い仮面と青い髪のシンガー yama さんの歩みを、ファンがこっそり年表にまとめた非公式の部屋です。これからも毎月、新しいできごとを書き足していきます。
